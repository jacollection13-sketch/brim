          Health steps

          A shortcut on your iPhone reads today's steps from the Health app and sends them here. Brim picks them up every minute or two while it is open.

          Keep the token private. Anyone who has it can change your step count.

          1. In the Shortcuts app, tap + and name it "Send steps to Brim".
          2. Add Find Health Samples. Set Type to Steps and add the filter Start Date is Today.
          3. Add Calculate Statistics and choose Sum.
          4. Add Format Date on the Current Date. Choose Custom and enter yyyy-MM-dd.
          5. Add Get Contents of URL. Paste the web address above, set Method to POST, and add two headers: apikey (the value above) and Content-Type set to application/json.
          6. Set Request Body to JSON with three fields: p_token (Text, your token), p_day (Text, the formatted date) and p_steps (Number, the Statistics result).
          7. Run it once and allow Health access to Steps. Then tap Sync now here.
          8. To run it automatically, open Automation in Shortcuts, tap +, choose Time of Day (for example noon, 6 pm and 10 pm), pick this shortcut and turn on Run Immediately. Health data can't be read while the phone is locked, so if a run doesn't update, tap the shortcut from your Home Screen.
